🤖 AGENT ANALYTICS

— это мощный Telegram-бот и Telegram Mini App (WebApp) для OSINT-анализа, пробива по базам данных и глубокой аналитики Telegram-аккаунтов с использованием искусственного интеллекта.

Проект объединяет в себе сканер Telegram-чатов, локальную базу данных (SQLite), интеграцию с внешними сервисами пробива и современный AI-помощник.

🚀 Основные возможности
🌐 1. Telegram Mini App (Веб-приложение)
Полноценный интерфейс внутри Telegram, который открывается по кнопке в боте.

Авторизация по коду: Безопасный вход в Mini App через генерацию 6-значного кода в Telegram-боте.

Поиск в базе бота: Мгновенный поиск людей по ID, @username или номеру телефона.

Поиск по ключевым словам: Поиск по миллионам сообщений в базе бота.

Пробив по базам (apisearch365): Поиск ФИО, даты рождения, телефона, email, адреса, паспорта, ИНН.

Поиск ВКонтакте (VK): Нахождение профилей VK.

Поиск Telegram: Глубокий поиск аккаунтов и чатов.

Проверка @username: Проверка занятости ника на 11 популярных платформах.

Проверка номера телефона: Определение страны, оператора, региона и типа номера. Отображение на интерактивной карте (Leaflet).

История поисков: Сохранение всех запросов за последние 30 дней с возможностью удаления записей.

🤖 2. AI-Помощник «Марыям» (Google Gemini)
Встроенный искусственный интеллект, который помогает пользователю и анализирует данные.

Чат-бот: Отвечает на любые вопросы пользователя в реальном времени.

AI-Резюме профиля: Анализирует сообщения пользователя и выдает краткую выжимку: о чем пишет, стиль общения, ключевые темы, психологический портрет.

AI-Эмоции (Тональность): Определяет эмоциональный окрас сообщений (позитив / нейтрально / негатив) с процентами.

AI-Определение языка: Анализирует, на каких языках пишет пользователь (русский, таджикский, английский, узбекский).

AI-Перевод: Перевод любого сообщения на русский, таджикский или английский язык в один клик.

AI-Похожие (Рекомендации): Находит пользователей с похожими интересами и общими чатами на основе анализа базы.

AI-График активности: Визуализация того, в какие часы и дни недели человек наиболее активен.

👤 3. Глубокая аналитика профиля (в Mini App)
При поиске пользователя выводится подробный HTML-отчет:

Аватарка: Загружается напрямую из Telegram.

Статистика: Количество сообщений, чатов, слов.

Группы и Каналы: Список всех чатов, где состоит пользователь (с кнопками «Открыть»).

История имён: Все имена и username, которые когда-либо были у пользователя.

Знакомые: Общие чаты с другими людьми.

Частые слова: Облако слов, которые человек использует чаще всего.

Сообщения: Последние сообщения с ссылками на оригинал.

Изменения профиля: История смены bio, имени, телефона.

🛡️ 4. Защита и модерация групп
Бот может работать как строгий модератор:

Анти-спам: Удаление рекламы и ссылок.

Анти-мат: Фильтрация нецензурной лексики и оскорблений.

Система предупреждений: 3 нарушения = автоматическая блокировка (мут) на 1 час.

Приветствие: Встречает новых участников правилами группы.

Удаление ботов: Автоматически кикает других ботов, если они не в белом списке (команда /allow_bot).

AI в группах: Если написать «Маям» или «Салом Маям», бот ответит как AI-помощник.

💰 5. Монетизация и биллинг
Алмазы: Внутренняя валюта (150 алмазов = 1 USD).

Подписки: Безлимитный доступ (1 месяц - 5 USD, 6 месяцев - 20 USD, 1 год - 45 USD).

API-токены: Продажа доступа к API бота для разработчиков (100, 500, 1000, 5000 запросов).

Ежедневный бонус: +10 алмазов каждый день.

Реферальная система: 50 алмазов за первого приглашенного, 20 за последующих.

Платежные шлюзы: Интеграция с OxaPay, CryptoCloud и CryptoBot для приема криптовалюты и карт.

Отслеживание: Услуга подписки на активность конкретного пользователя (20 алмазов / 7 дней).

🔄 6. Сканер (Парсер)
Работает на двух аккаунтах (АКК_1 и АКК_2) через библиотеку Telethon.

Автоматически собирает данные об участниках, сообщениях, группах и каналах.

Работает по расписанию (каждые 4 часа).

Сохраняет всю историю в локальную базу данных SQLite с возможностью ротации (разделения) файлов БД при достижении 2 ГБ.

Бэкенд:

Python 3.10+

aiohttp (HTTP-сервер для API)

sqlite3 (база данных)

httpx (запросы к AI и сторонним API)

phonenumbers (парсинг телефонов)

openpyxl / pandas (экспорт в Excel)

Фронтенд (Mini App):

HTML5 / CSS3 / Vanilla JavaScript

Telegram WebApp API

Chart.js (графики)

Leaflet (карты)

Искусственный интеллект:

Google Gemini API (через OpenRouter или прямой доступ).

Для туннеля используется ngrok.

⚙️ Установка и запуск (Локально)
Клонируйте репозиторий:

bash
git clone https://github.com/abulov05/agent-miniapp.git
cd agent-miniapp
Установите зависимости:

bash
pip install telethon aiohttp openpyxl pandas phonenumbers httpx cachetools
Настройте данные:

В файле import hashlib.txt укажите ваши API_ID, API_HASH, BOT_TOKEN.

Вставьте ключи от OxaPay, CryptoCloud, CryptoBot, Gemini API.

В файле index.html (Mini App) в переменной CONFIG.API_BASE укажите ваш ngrok-адрес.

Запустите бота:

bash
python "import hashlib.txt"
(При первом запуске потребуется ввести номер телефона и код для аккаунтов-сканеров АКК_1 и АКК_2)

Запустите ngrok:

bash
ngrok http 8081
Обновите ngrok-ссылку в Mini App:
Скопируйте новый URL из ngrok и вставьте его в CONFIG.API_BASE в файле index.html.
